# Lung Cancer Analysis

This project analyzes lung cancer patient health and treatment records using Python and data analysis techniques.

## Topics Covered

- Data cleaning and preprocessing
- Duplicate removal
- Data type conversion
- Treatment duration analysis
- Survival rate analysis
- Country-level analysis
- Patient filtering and aggregation

## Tools Used

- Python
- Pandas
- Data Analysis
